Если не работает модуль Rosreestr Tools
=========================================

Эта инструкция предназначена для случаев, когда доступ к НСПД есть, но функции модуля заблокированы.

Проверка доступности GeoServices
-------------------------------

Проверьте, разрешён ли в локальной сети организации доступ ко внешнему серверу по адресу https://geoservices.nextgis.com. Это можно сделать, открыв ссылку в браузере с того устройства, на котором вы используете модуль Rosresstr Tools.

Нет - системному администратору нужно разрешить доступ к этому адресу.

Да - переходите к следующему шагу.


Проверка API-ключа
-------------------

Зайдите на https://geoservices.nextgis.com/settings/profile, авторизовавшись под облачным пользователем, для которого подключён Премиум.

Скопируйте API-ключ и подставьте его в ссылку запроса любого тайла ПКК, например:

``https://geoservices.nextgis.com/raster/pkk/ngrr1/11/1195/595.png?apikey=ваш_ключ``

Проверьте, открывается ли тайл по этой ссылке в браузере.

Да - переходите к следующему шагу.

Проверка работы модуля через прямой доступ
------------------------------------------

Убедитесь, что в вашей сети доступен адрес https://my.nextgis.com.

В NextGIS QGIS в Параметры - NextGIS - Параметры авторизации установите адрес входа https://my.nextgis.com (облачный сервер авторизации).

В NextGIS Account Toolbar авторизуйтесь под облачным пользователем.

Убедитесь, что есть надпись "На поддержке".

Проверьте, работает ли модуль Rosreestr Tools.

Да - переходите к следующему шагу.

Связь облачного аккаунта с NextGIS ID on-premise
-------------------------------------------------

Зайдите на свой сервер авторизации и в разделе NextGIS ID on-premise скопируйте GUID.

Зайдите на https://my.nextgis.com/myngidonpremises под облачным пользователем. Убедитесь, что в разделе "Идентификатор" вписан GUID из NextGID ID on-premise.

Да - переходите к следующему шагу.

Проверка работы модуля через собственный сервер авторизации
------------------------------------------------------------

В NextGIS QGIS в Параметры - NextGIS - Параметры авторизации поменяйте адрес входа на свой сервер авторизации.

В NextGIS Account Toolbar авторизуйтесь под пользователем, созданным в NextGIS ID on-premise.

Проверьте, работает ли модуль Rosreestr Tools.
